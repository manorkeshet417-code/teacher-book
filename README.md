# יומן המורה

אתר לניהול כיתה בשביל המורה: כיתות ותלמידים, נוכחות והתנהגות, ציונים, שיעורי בית, יומן שיעורים, מערכת שעות, לוח שנה, הודעות להורים, כלי כיתה (תלמיד אקראי, קבוצות, טיימר) ודוחות.

- פותחים את `index.html` בדפדפן, ואין צורך בהתקנה.
- כל המידע נשמר בדפדפן שבו עובדים (localStorage). כדי לא לאבד אותו, מורידים גיבוי מדף ההגדרות.
